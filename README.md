## 🌟 Overview

**CivicFix** is an end-to-end smart municipal grievance redressal platform that connects **citizens, municipal administrators, and field officers** through one unified digital workflow.

The platform transforms traditional complaint handling into a transparent, trackable, and evidence-driven process.

Citizens can report civic problems with **photos and GPS location**, administrators can review and assign complaints, and field officers can update progress and upload **before/after resolution evidence**.

```text
                    🏙️ CIVICFIX
                         │
             ┌───────────┼───────────┐
             ↓           ↓           ↓
        👤 CITIZEN   👨‍💼 ADMIN    👷 OFFICER
             │           │           │
             └───────────┼───────────┘
                         ↓
                🔄 Complaint Workflow
                         ↓
          📍 Track → Assign → Resolve
                         ↓
                📸 Proof of Resolution
                         ↓
                 ⭐ Citizen Feedback
```

# 👤 Citizen Portal

The Citizen Portal provides a simple interface for residents to report and monitor civic issues.

### 📝 Complaint Reporting

Citizens can report:

* 🕳️ Potholes
* 🗑️ Garbage accumulation
* 💡 Street light problems
* 💧 Water leakage
* 🚰 Drainage issues
* 🚦 Traffic signal problems
* 🏗️ Public property issues
* 🌳 Other municipal problems

### 📸 Evidence Upload

Citizens can attach photographs and capture the complaint location using GPS.

### 🔄 Complaint Tracking

Every complaint receives a unique tracking ID:

```text
CF-2026-XXXX
```

The complaint progresses through:

```text
📝 Submitted
      ↓
📋 Assigned
      ↓
🔧 In Progress
      ↓
✅ Resolved
```

### 🔳 QR Code Tracking

Each complaint can generate a QR code that allows users to quickly access its public tracking information.

### 📄 PDF Receipt

Citizens can generate downloadable complaint receipts containing complaint and resolution information.

### ⭐ Rating & Feedback

After resolution, citizens can provide:

```text
⭐ ⭐ ⭐ ⭐ ⭐
```

along with feedback about the service.

# 👷 Officer Dashboard

Field officers receive a dedicated workspace for handling assigned municipal complaints.

### Officer capabilities

* 📋 View assigned complaints
* 🔍 Open complaint details
* 📍 View complaint location
* 🔄 Update complaint status
* 🔧 Mark work as **In Progress**
* 📸 Upload resolution proof
* 📝 Add resolution notes
* ✅ Mark complaint as **Resolved**

### Resolution Workflow

```text
Assigned
   ↓
In Progress
   ↓
Repair / Field Work
   ↓
Upload After Photo
   ↓
Add Resolution Notes
   ↓
Resolved
```

This creates an evidence-based resolution process instead of simply marking a complaint as completed.

# ⏱️ SLA Monitoring

CivicFix supports SLA-based complaint monitoring.

Example target:

```text
⏱️ Resolution Target
       ↓
     48 Hours
       ↓
 ┌───────────────┐
 │ SLA Countdown │
 └───────────────┘
       ↓
 ┌───────────────┐
 │   Resolved    │ → ✅
 └───────────────┘

OR

 ┌───────────────┐
 │ Time Exceeded │ → 🚨 SLA Breached
 └───────────────┘
```

Administrators can identify overdue complaints and prioritize municipal resources accordingly.

# 🚀 Getting Started

## 1️⃣ Prerequisites

Install:

* Python 3.10+
* Node.js 18+
* npm
* Git

---

## 2️⃣ Clone Repository

```bash
git clone https://github.com/Nithinreddy1538/CivicFix.git

cd CivicFix
```

---

# ⚙️ Backend Setup

```bash
cd backend
```

### Create Virtual Environment

### Windows

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py migrate
```

### Create Demo Users

```bash
python manage.py seed_users
```

### Start Django Server

```bash
python manage.py runserver
```

Backend:

```text
http://127.0.0.1:8000/
```

---

# 🎨 Frontend Setup

Open another terminal:

```bash
cd CivicFix/frontend
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Frontend:

```text
http://localhost:5173/
```
